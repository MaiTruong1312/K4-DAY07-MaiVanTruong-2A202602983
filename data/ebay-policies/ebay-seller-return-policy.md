# Setting up a seller return policy

Sellers must state whether they accept returns and, if so, the conditions, including who pays return shipping and the accepted period after a sale. The policy must be clearly stated in each listing.

Available standard choices are:

- No returns
- 30-day buyer-paid returns
- 30-day free returns
- 60-day buyer-paid returns
- 60-day free returns

Fourteen-day returns can be offered for camera drones, camera lenses, collectibles and art, digital cameras, jewelry, and medical and mobility items.

## Automation rules

A seller can automatically approve selected returns, send an immediate refund while allowing the buyer to keep an item when return shipping is more expensive than the item, and choose different return addresses for different items.

Rules can use the refund amount and return reason. Changes apply to future requests, not returns already in progress. Return-address rules can use refund amount, reason, or item category; rule order determines priority.

Address types include the seller's registration address, primary return address, address closest to the buyer, and the original ship-from address. Approval and refund rules are evaluated before address rules. If a request matches only an address rule, the seller must manually accept the return before that address rule takes effect.

## EU right of withdrawal

Consumer buyers in the European Union may withdraw from a purchase contract by returning the item within **14 days**. Sellers listing on an EU site must edit their policies to comply. Even when a listing says no returns, the eBay Money Back Guarantee may allow a return when the item does not match the description.
