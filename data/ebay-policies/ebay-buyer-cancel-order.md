# How buyers can cancel an order

If a buyer changes their mind about a purchase, they may submit a cancellation request. The seller can accept or decline it. The request should be submitted as quickly as possible; a seller cannot cancel after the order has shipped or when it was purchased during an eBay Live event.

If an order contains multiple items, the entire order must be canceled; individual items cannot be canceled.

## Request procedure

1. Open **Purchase history** and find the order.
2. From **More actions**, select **Cancel this order**. If the option is absent, the order is not eligible.
3. Select **Submit**.

The seller has **3 calendar days** to accept or decline the request. If accepted, eBay sends a confirmation by registered email and eBay Messages.

A buyer can no longer cancel after requesting a return or reporting that the item has not arrived. If the seller declines or has already shipped the item, the buyer must wait to receive it and then request a return. If the item does not arrive, the buyer may report it after the estimated delivery date passes.
